众所周知，作为一个每周风雨无阻奔波在各大前尘老本里摸大铁、摸奇遇、摸挂件的刷本狂魔，最痛苦的事情是：

每个 Boss 打完掉一地破烂，背包分分钟被各种低级装备和破铜烂铁塞得满满当当，得一遍一遍手动卖。校服牌子还卖不掉，得手动销毁。虽然茗伊插件有【跳过拾取】和【自动售卖】功能，但是苦于要手动添加所有的物品名称，太牢了

💡 灵感与渊源

其实关于副本掉落数据这块，社区里一直有大佬在探索：

  • 荷花鲤 大佬的《剑三插件数据文件解析》（tool/60356），是最早能够获取到的快速导出物品的工具，最初就是在大佬的工具上导出数据；
  • 后来 柳阮阮 在 tool/64676 帖子里分享的魔盒 API 抓包遍历思路（通过 fb/boss?MapID 遍历副本 Boss，再抓取 fb/drop/v2/ 的全量掉落），也点亮了自动化爬虫的路子。

但问题也摆在眼前：
总不能让普通玩家每次都去抓包、或者拿记事本改 lua 数据吧？而且【跳过拾取】和【自动出售】始终得分两次导入，对于我这种极致懒狗来说，还是不够省事。

既然数据源和底层格式都摸透了，为什么不写一个网页工具，把全赛季所有副本的掉落全自动整理好？同时把【跳过拾取】和【自动出售】导出成一个文件，进游戏点一次导入直接全解决？！

🤖 拉出新牛马组合通宵大战

说干就干。这次我换上了新工具人组合：Codex + Google Antigravity，把魔盒全量 API 爬虫逻辑、多级分类规则以及茗伊 .us.jx3dat 的二进制/文本编码规范一股脑甩给了它们。

经过抓包清洗、分类整理、防冲突逻辑、配色调整与离线打包优化后：

游戏内使用方法（极简两步）

  1. 在工坊右上角点击 【⚡ 导出综合配置】，把下载的 掉落工坊_综合配置_YYYYMMDD-HHMMSS.us.jx3dat 文件保存在桌面或下载目录；
  2. 进游戏按 Ctrl + M 打开 茗伊插件集 -> 【系统】 -> 【全局设置】 -> 【导入配置】 -> 直接从桌面选择刚才的文件点导入。收工！
